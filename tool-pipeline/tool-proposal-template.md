| Field | Value |
|-------|-------|

| **Backlink Potential** | Will other sites link to this? |
| **Seasonality** | Peak months or evergreen |

---

### Why Build This Now

Explain the urgency or timing advantage. Examples:
- Trending keyword × rising
- Competitor tools are outdated / broken
- Existing gap in our tool portfolio
- Seasonal timing (e.g., tax calculators in March)

### Risks / Considerations

- Technical challenges
- Maintenance overhead
- Competition intensity
- AdSense policy risks (e.g., health/finance tools)
- Ongoing costs (API fees, hosting)

### Strategic Fit

How does this tool contribute to the bigger picture?
- Fills a category gap
- Drives internal linking to other tools
- Targets a high-value keyword cluster
- Attracts returning users (utility)
